WhatsApp Chat Button — A Floating Chat Button on Every Page

No snippet to drag, no code: enable it once and every page of the website gets a floating round button that opens a WhatsApp chat with your number, pre-filled with a message of your choice.

✓ Odoo 17.0✓ Odoo 18.0✓ Odoo 19.0

How it works

  1. Go to Website › Configuration › Settings and open your website.
  2. Open the WhatsApp Button tab: enable it, set your number (with country code) and an optional message.
  3. Save. The floating button appears immediately on every page of that website.

Details

  • Position: bottom-right or bottom-left.
  • Multi-website ready: each website has its own number, message and on/off switch.
  • Opens wa.me in a new tab — no external script, nothing tracks your visitors, nothing is loaded unless the button is enabled.

Technical

One new field group on the website model (wa_button_*) plus a small website.layout template extension and a stylesheet. No JavaScript, no new model, no security rules.

Frequently asked questions

Does this track visitors or load an external script?
No — the button links directly to wa.me. Nothing is loaded or tracked unless you enable it, and no analytics script is added.
Can each website show a different number?
Yes — fully multi-website: each site keeps its own number, message and on/off switch.
Do I need a WhatsApp Business account or API access?
No — it's a plain wa.me chat link. Any WhatsApp number, personal or business, works.
